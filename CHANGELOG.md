# Changelog

## 0.1.0

- Initial FxDesktop package scaffold.
- Added desktop-first component registry and `Fx*` naming convention.
- Added `FxFlexLayout`, `FxGridLayout`, `FxFlexItem`, `FxGridArea`, and
  `FxGridPlacement`.
- Added serializable `FxLayoutSpec`, `FxFlexLayoutManager`, and
  `FxGridLayoutManager`.
- Added first Xojo-first controls: `FxListBox` and `FxGrid`.
- Added English README, developer docs, testing docs, example gallery, and CI
  harness.
